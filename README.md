# 课程雷达（桌面版）

## 功能

- 导入课表（合并）：支持 `.json/.xls/.xlsx`
- 替换课表（覆盖）：支持 `.json/.xls/.xlsx`
- 删除当前课表
- 导出备份（JSON）
- 编辑、删除当前课表中的单条课程
- 支持按住 Ctrl + 滚轮缩放桌面界面
- 手机版（PWA）支持同样导入能力

## 数据保存

课表会自动保存到应用数据目录。  
下次打开软件时会自动加载，不需要重新导入。

## 运行与打包

1. 安装依赖：`npm install`
2. 本地运行：`npm start`
3. 打包安装版：`npm run build`
4. 打包单文件版：`npm run build:portable`

## 手机版使用

1. 在电脑执行：`npm run mobile:serve`
2. 让手机和电脑连同一个 Wi-Fi
3. 手机浏览器打开终端里显示的 `http://你的局域网IP:5173`
4. 打开后可“添加到主屏幕”，像 App 一样使用
